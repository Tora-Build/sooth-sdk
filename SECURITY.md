# Security Policy

## Reporting a vulnerability

**Do not open a public GitHub issue for security bugs.**

Email `security@tora.build` with:

- A description of the vulnerability
- Steps to reproduce or a proof-of-concept
- The potential impact

**Response SLA:**
- Acknowledgment within 72 hours
- Triage decision within 7 days

We will coordinate a fix and disclosure timeline with you privately before
any public announcement.

## Supported versions

The utility-only 1.0.0 line is pending release. This repository now maintains
SQF utilities. The removed 0.x protocol and CLI APIs are retired here; this
policy does not claim continued support for them.

## Out of scope

- Issues in dependencies (report upstream, cc us if critical)
- Theoretical attacks without demonstrated impact
- Issues requiring physical access to a user's device
