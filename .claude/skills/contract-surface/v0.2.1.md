## TruthMarket

Each market is a proxy to this implementation. One instance per market.

### Reads

| Function | Returns | Notes |
|----------|---------|-------|
| `creator()` | address | |
| `adjudicator()` | address | AdjudicatorBase instance |
| `launchpadEngine()` | address | |
| `questionHash()` | bytes32 | Hash of the question string. Actual string only in `MarketCreated` event. |
| `startTime()` | uint64 | |
| `deadline()` | uint64 | |
| `tStar()` | uint64 | Resolution time (set by adjudicator) |
| `invalidationBuffer()` | uint64 | |
| `winningOutcome()` | uint8 | 0=NO, 1=YES, 2=INVALID |
| `state()` | uint8 | MarketState enum |
| `isLive()` | bool | |
| `isResolving()` | bool | |
| `isAttested()` | bool | |
| `isSettled()` | bool | |
| `getRedemptionValue(outcome)` | uint256 | |

### Writes

| Function | Notes |
|----------|-------|
| `resolve(outcome, _tStar)` | Adjudicator calls after deadline. Sets outcome + tStar. |
| `attest()` | Adjudicator attests to resolution. Starts veto window. |
| `veto()` | Adjudicator veto during veto window. |
| `settle()` | Finalizes resolution after veto window. Triggers payout availability. |
| `invalidate()` | Adjudicator or authorized caller marks market INVALID. |

### Lifecycle state machine

```
IDLE → ACTIVE (startTime reached)
     → RESOLVING (adjudicator calls resolve())
     → ATTESTED (adjudicator calls attest())
     → SETTLED (anyone calls settle() after veto window) ← terminal
     → INVALID (invalidate() called) ← terminal
     can VETO back from ATTESTED → RESOLVING
```

### Key events

`MarketCreated` (market indexed; questionHash, **question string**, startTime, deadline), `MarketResolved` (market indexed; outcome, tStar), `MarketAttested` (market indexed; outcome), `MarketSettled` (market indexed), `MarketVetoed` (market indexed; previousOutcome, previousTStar), `MarketInvalidated` (market, caller both indexed)

> Note: The question text is ONLY available in the `MarketCreated` event. `questionHash()` returns a bytes32 hash.

### Key custom errors

`NotAdjudicator`, `NotAttested`, `NotResolving`, `AlreadySettled`, `DeadlineNotPassed`, `InvalidOutcome`, `TStarInFuture`, `TStarAfterDeadline`, `InfiniteDeadline`, `BeforeStart`

## Cross-contract call graph (simplified)

```
User
 ├─ AMMEngine.tradePositions()  →  FeeRouter.calculateAndDistributeFee()
 ├─ AMMEngine.settlePosition()  →  (reads TruthMarket.isSettled + winningOutcome)
 ├─ AMMEngine.redeemLP()
 ├─ SoothBook.buyYes/buyNo()    →  OrderEngine.fillOrder() + creditShares/debitShares
 ├─ SoothBook.mint/merge()      →  OrderEngine.mint/merge()
 ├─ OrderEngine.settlePosition() → (reads TruthMarket.isSettled + winningOutcome)
 └─ OrderEngine.mint/merge()    →  (direct collateral ↔ shares)

LaunchpadEngine.createMarket()
 ├─ AdjudicatorRegistry.isApproved()
 ├─ AdjudicatorBase.configureMarket()
 ├─ AMMEngine.initializeMarket()
 ├─ AMMEngine.setLPToken()
 ├─ FeeRouter.registerMarket()
 └─ OrderEngine.registerMarket()

FeeRouter  (when graduation threshold reached)
 └─ LaunchpadEngine.notifyGraduation()
    └─ SoothBook.registerMarketFromEngine()
```
