# Sync Deployments Workflow - V10

Use this workflow after any V10 contract deployment to ensure the frontend is using the correct addresses.

## Quick Start

```bash
# From repo root
./apps/web/scripts/sync-deployments.sh
```

This script:
1. Reads from `packages/contracts-core/deployments/{chain}.json` (source of truth)
2. Merges all networks into `apps/web/src/config/deployments.json`

## Source of Truth

**TypeScript deployment outputs are the canonical source:**
- `packages/contracts-core/deployments/baseSepolia.json`
- `packages/contracts-core/deployments/monadTestnet.json`
- `packages/contracts-core/deployments/arcTestnet.json`

These files are generated by `deploy-multichain.ts` and should NOT be manually edited.

## Prerequisites

- V10 contracts deployed successfully via `bun run script/deploy-multichain.ts`
- `packages/contracts-core/deployments/{chainName}.json` exists for your target network
- `jq` installed (for JSON processing)

## 1. Run the Sync Script

```bash
./apps/web/scripts/sync-deployments.sh
```

Expected output:

## 2. Verify On-Chain State

After syncing, verify the contracts are actually live:

```bash
cd packages/contracts-core
source .env

# Check Collateralizer
COLLAT=$(jq -r '.contracts.Collateralizer' deployments/baseSepolia.json)
cast call $COLLAT "usdc()" --rpc-url https://sepolia.base.org

# Check TickBookPoolManager
POOL=$(jq -r '.contracts.TickBookPoolManager' deployments/baseSepolia.json)
cast call $POOL "owner()" --rpc-url https://sepolia.base.org
```

**Expected**: All calls return valid data (not `0x` or revert)

## 3. Test Frontend

```bash
cd apps/web
pnpm dev
```

Verify in browser console:
- No "Contract not found" errors
- No "Collateralizer: not registered" errors
- Markets load with correct probabilities

## 4. Commit Changes

```bash
git add apps/web/src/config/deployments.json
git commit -m "chore: sync V10 deployment configs"
```

## Troubleshooting

### "Collateralizer: not registered" error

**Cause**: Market address not registered with Collateralizer contract

**Solution**:
1. Check the market was deployed with the SAME Collateralizer
2. Verify market registration: `cast call $COLLAT "getOutcomeTokens(address)" $MARKET`
3. If not registered, create market via interactive CLI

### Frontend shows old addresses

**Cause**: Browser cache or outdated config

**Solution**:
1. Hard refresh browser: `Cmd+Shift+R`
2. Clear localStorage: `localStorage.clear()`
3. Re-run sync script
4. Check `version` field updated in deployments.json

### Script says "No json deployment files found"

**Cause**: Deployment artifacts missing

**Solution**: Run the TypeScript deployment script first:
```bash
cd packages/contracts-core
bun run script/deploy-multichain.ts --chains=baseSepolia
```

```
apps/web/
  src/config/

  scripts/

```

## Adding a New Network

1. Add chain config in `packages/contracts-core/script/chainConfigs.ts`
2. Deploy contracts: `bun run script/deploy-multichain.ts --chains=newChainName`
3. Run sync script — it auto-detects new networks from filenames
4. Add chain config in frontend `wagmi.config.ts` if needed

## Success Criteria

Deployment sync is successful when:
- Sync script runs without errors
- On-chain verification passes
- Frontend loads without contract errors
- Markets show correct probabilities
- Trades execute successfully
