## Zero-Sum Validation

**Status**: ✅ FIXED (2026-01-23)

The `checksum` command now properly validates zero-sum:
```
Total Accounted Δ = USDC Minted Δ → Checksum = 0.00 USDC
```

### Fix Applied

**Problem**: Checksum showed -71.24 USDC imbalance after scenario completion.

**Root Cause**: AMM positions (YES/NO shares from pre-graduation trades via `LaunchpadEngine.tradePositions`) were not being tracked. Bob's AMM positions had value when market settled to YES, but this value wasn't captured.

**Solution**: Added `AMMEngine.getPosition(market, user)` tracking to `wallet.ts`:
- Extended `ActorPositions` with `ammYes` and `ammNo` fields
- Updated `snapshot()` and `checksum()` to fetch AMM positions per actor
- Updated `calculateActorTotalValue()` to include AMM positions in total YES/NO calculations
- AMM positions now display in breakdown as `amm:X/Y`
