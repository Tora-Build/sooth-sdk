# How to Apply Agent Workflows in Cursor

Type a slash command in Cursor Chat/Composer:

| Command | When to Use |
|---------|-------------|
| `/preflight` | Start of session |
| `/evm-dev` | Solidity work |
| `/frontend-dev` | React/TS work |
| `/fullstack-dev` | Cross-stack |
| `/deploy` | Before deployment |
| `/deploy-sync` | After deployment |
| `/coordinator` | End of session |
| `/auditor` | Code review |
| `/sop` | Edit workflows |

See `.agent/GUIDE.md` for full reference.
